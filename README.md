# D.R.E.S.S. - Digital Retail Enterprise Sales System

Sistema web para gerenciamento de loja de roupas, com controle de produtos, clientes, vendas, estoque, relatórios e autenticação com JWT.

## Objetivo do projeto

O D.R.E.S.S. foi desenvolvido como projeto acadêmico da disciplina de Desenvolvimento Web.  
O sistema permite que uma loja de roupas gerencie seus produtos, clientes e vendas por meio de uma API REST integrada a uma interface web.

## Funcionalidades

- Login com autenticação JWT
- Cadastro, listagem, edição e exclusão de produtos
- Controle de estoque
- Cadastro, listagem, edição e exclusão de clientes
- Registro de vendas
- Atualização automática do estoque após venda
- Relatórios de vendas
- Validação de campos obrigatórios
- Proteção de rotas da API
